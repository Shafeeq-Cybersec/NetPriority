🔴 The Problem

A home connection must simultaneously serve video calls, gaming, streaming, bulk downloads and cloud backup.

Static priority rules fail when demand changes. High throughput alone is insufficient — large queues introduce delay and jitter that break real-time apps.

📋 Test Scenarios
⬇
ISO download starts mid-video-call → bulk queue capped, call latency protected
📉
WAN drops 100 → 20 Mbps → shaping policy recalculated in real time
🎮
3 TVs + gaming → fair scheduling balances service quality across all devices
